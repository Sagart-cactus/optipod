Private networks and production settings
Before onboarding, edit the generated plan to reference existing imagePullSecrets, proxySecret, prometheusSecret, prometheusAuth and prometheusCASecret. Copy referenced Secrets into the agent and optimizer namespaces as needed. Use versioned private images. Keep secret values in your secret manager. HTTPS trust comes from the enrollment package.

        
Upgrade, reconnect or uninstall
Rerun with the saved state directory for compatible upgrades. To replace an expired or revoked identity, reconnect this registration, download a fresh enrollment file and add --reenroll. Revoke the previous runtime credential after the replacement is healthy. Agent removal retains its queue PVC, workload optimizer and central history.
