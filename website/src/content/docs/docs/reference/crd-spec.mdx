This page provides the complete technical specification for the OptimizationPolicy Custom Resource Definition (CRD).

## CRD Metadata

```yaml
apiVersion: apiextensions.k8s.io/v1
kind: CustomResourceDefinition
metadata:
  name: optimizationpolicies.optipod.io
spec:
  group: optipod.io
  versions:
    - name: v1alpha1
      served: true
      storage: true
  scope: Namespaced
  names:
    plural: optimizationpolicies
    singular: optimizationpolicy
    kind: OptimizationPolicy
    shortNames:
      - optpol
      - op
```

## Spec Schema

### spec.mode

```yaml
mode:
  type: string
  enum:
    - Recommend
    - Auto
    - Disabled
  description: Operational mode for the policy
```

### spec.updateStrategy

```yaml
updateStrategy:
  type: string
  enum:
    - ServerSideApply
    - Webhook
  default: ServerSideApply
  description: How to apply recommendations in Auto mode
```

  type: object

## Validation Rules

### Cross-Field Validation

```yaml
x-kubernetes-validations:
  - rule: "self.spec.mode == 'Auto' || !has(self.spec.safetyConfig)"
    message: "safetyConfig is only valid in Auto mode"

  - rule: "self.spec.updateStrategy == 'ServerSideApply' || !has(self.spec.ssaConfig)"
    message: "ssaConfig is only valid with ServerSideApply strategy"

  - rule: "self.spec.updateStrategy == 'Webhook' || !has(self.spec.webhookConfig)"
    message: "webhookConfig is only valid with Webhook strategy"

  - rule: "int(self.spec.resourceBounds.cpu.min) < int(self.spec.resourceBounds.cpu.max)"
    message: "cpu.min must be less than cpu.max"

  - rule: "int(self.spec.resourceBounds.memory.min) < int(self.spec.resourceBounds.memory.max)"
    message: "memory.min must be less than memory.max"
```

## RBAC Requirements

### Cluster Role

```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: optipod-operator
rules:
  - apiGroups: ["optipod.io"]
    resources: ["optimizationpolicies"]
    verbs: ["get", "list", "watch"]

  - apiGroups: ["optipod.io"]
    resources: ["optimizationpolicies/status"]
    verbs: ["get", "update", "patch"]

  - apiGroups: ["apps"]
    resources: ["deployments", "statefulsets", "daemonsets"]
    verbs: ["get", "list", "watch", "update", "patch"]

  - apiGroups: ["batch"]
    resources: ["jobs", "cronjobs"]
    verbs: ["get", "list", "watch", "update", "patch"]
```
