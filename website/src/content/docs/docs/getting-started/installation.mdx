## Prerequisites

Before installing OptiPod, ensure you have:

- Kubernetes cluster (v1.19+)
- `kubectl` configured to access your cluster
- Helm 3.x (for Helm installation method)
- A metrics provider (Prometheus or metrics-server)

## Installation Methods

<Tabs>
  <TabItem label="Helm">

### Install with Helm

The easiest way to install OptiPod is using Helm:

```bash
# Add the OptiPod Helm repository
helm repo add optipod https://sagart-cactus.github.io/optipod/charts
helm repo update

# Install OptiPod
helm install optipod optipod/optipod \
  --namespace optipod-system \
  --create-namespace
```

### Custom Configuration

You can customize the installation with a values file:

```yaml
# values.yaml
controller:
  replicaCount: 2
  resources:
    limits:
      cpu: 500m
      memory: 512Mi
    requests:
      cpu: 100m
      memory: 128Mi

# Prometheus configuration (if using Prometheus)
prometheus:
  address: http://prometheus-server.monitoring.svc:9090
  # Optional: Configure authentication
  # auth:
  #   type: bearer
  #   token: "your-token"
```

Install with custom values:

```bash
helm install optipod optipod/optipod \
  --namespace optipod-system \
  --create-namespace \
  -f values.yaml
```

  </TabItem>
  <TabItem label="kubectl">

### Install with kubectl

You can also install OptiPod directly using kubectl:

```bash
# Install CRDs
kubectl apply -f https://raw.githubusercontent.com/Sagart-cactus/optipod/main/config/crd/bases/optipod.optipod.io_optimizationpolicies.yaml

# Install OptiPod operator (use Helm for production)
kubectl apply -k https://github.com/Sagart-cactus/optipod/config/default
```

:::note
For production deployments, we recommend using Helm for easier configuration and upgrades.
:::

## Verify Installation

Check that OptiPod is running:

```bash
kubectl get pods -n optipod-system
```

You should see:

```
NAME                              READY   STATUS    RESTARTS   AGE
optipod-operator-xxxxxxxxx-xxxxx  1/1     Running   0          30s
```

Check the operator logs:

```bash
kubectl logs -n optipod-system -l app=optipod-operator
```

## Configure Metrics Provider

OptiPod needs access to metrics to make recommendations. Configure your metrics provider via Helm values:

<Tabs>
  <TabItem label="Prometheus">

### Prometheus Configuration

Configure Prometheus in your Helm values:

```yaml
# values.yaml
prometheus:
  address: http://prometheus-server.monitoring.svc:9090

  # Optional: Configure authentication
  auth:
    type: bearer  # or "basic"
    token: "your-prometheus-token"  # pragma: allowlist secret
    # For basic auth:
    # username: "user"
    # password: "pass"  # pragma: allowlist secret
```

Install with Prometheus configuration:

```bash
helm install optipod optipod/optipod \
  --namespace optipod-system \
  --create-namespace \
  -f values.yaml
```

See the [Prometheus Setup Guide](/optipod/docs/prometheus-setup) for detailed configuration options.

  </TabItem>
  <TabItem label="metrics-server">

### metrics-server Configuration

OptiPod can use metrics-server for basic CPU and memory metrics:

```yaml
# values.yaml
metricsServer:
  enabled: true
  # Optional: Configure sampling
  minSamplesRequired: 10
```

:::note
metrics-server provides basic CPU and memory metrics. For more detailed recommendations and historical data, consider using Prometheus.
:::

## Troubleshooting

If you encounter issues during installation:

- Check that your cluster meets the prerequisites
- Verify RBAC permissions are correctly configured
- Ensure your metrics provider is accessible
- Review the [Troubleshooting guide](/optipod/docs/advanced/troubleshooting)

## Uninstallation

To remove OptiPod from your cluster:

<Tabs>
  <TabItem label="Helm">

```bash
helm uninstall optipod -n optipod-system
kubectl delete namespace optipod-system
```

  </TabItem>
  <TabItem label="kubectl">

```bash
# Delete CRDs and resources
kubectl delete -k https://github.com/Sagart-cactus/optipod/config/default
kubectl delete -f https://raw.githubusercontent.com/Sagart-cactus/optipod/main/config/crd/bases/optipod.optipod.io_optimizationpolicies.yaml
```
