# Privacy Policy

OptiPod is an open-source Kubernetes operator that runs entirely within your cluster. This privacy policy describes how the OptiPod website handles information.

## Information We Collect

The OptiPod website (https://sagart-cactus.github.io/optipod/) is a static site hosted on GitHub Pages. We do not collect, store, or process any personal information through this website.

## OptiPod Operator

The OptiPod Kubernetes operator:
- Runs entirely within your Kubernetes cluster
- Does not send any data to external services
- Does not require a SaaS backend
- Does not collect telemetry or usage data

All metrics and recommendations are processed locally within your cluster.

## GitHub

This website is hosted on GitHub Pages. GitHub may collect technical information such as IP addresses and user-agent strings as described in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

## Third-Party Links

This website contains links to external sites (such as GitHub repositories). We are not responsible for the privacy practices of these external sites.

## Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date.

## Contact

If you have questions about this Privacy Policy, please open an issue on our [GitHub repository](https://github.com/Sagart-cactus/optipod/issues).
